# Quote selection first answer, operator-started Deep dive, stdlib orchestration

The ask's three phases are re-cut (grill session, 2026-09-12). Phase 1 becomes the Quote selection: the recorded `HYBRID_COMPLETION` recall and its Evidence pool are untouched — the phone gate still records here, the pool stays visible in the phase-1 tab and remains phase 2's input — but the answer rendered on the sheet becomes ten verbatim Book sentences (guarded 4–12) picked from that pool by one `glm-5.3-flash` call, each sentence carrying its own Citation and passing the existing verbatim guard; the streamed prose is no longer the displayed answer. Phase 2 is unchanged. Phase 3 becomes the Deep dive: an operator-started button on the phase-3 tab — overturning ADR 0005's auto-start, so an ask no longer burns a multi-minute dive by itself — running a planned study of the same question: Planner (`glm-5.3`, thinking on) → four to six parallel searchers on the 8001 service → at most one gap round (two retrieval rounds total) → Synthesizer (`glm-5.3`), returning 2,000–4,000 Farsi words in five to eight headed sections plus a closing references list, every body paragraph a Quoted paragraph (the phase-2 block format, guards, page labels, and truncation continuation reused as-is).

The dive runs server-side in `ui/serve.py` behind an in-process job registry (dict + lock + threads; the sheet polls a status endpoint, so a browser refresh reconnects): at most one dive per phone and three globally, further requests rejected with a busy message rather than queued; a new ask aborts an in-flight dive; the dive belongs to the chat phase 1 recorded and never counts against the phone gate. Orchestration stays stdlib-only — the planner/writer/continuation composer already runs this call shape in production, and the fan-out needs nothing beyond threads. A sheet restart still kills in-flight dives (accepted, same as today's phases); if that ever matters, the recorded upgrade is durable execution (Temporal via PydanticAI or the OpenAI Agents SDK), not a queue.

## Considered options

- Mastra as the agent harness. Rejected: TypeScript/Node-only with no Python SDK — it would add a Node sidecar to the Python/Postgres compose stack purely for primitives stdlib threads already provide.
- The OpenAI Python SDK as the orchestration layer. Rejected: the repo is deliberately zero-runtime-dependency (bare `python:3.12-slim` image), the stdlib composer already runs the same call shape, and `AsyncOpenAI` across `asyncio.gather` batches carries a known connection-reuse sharp edge (openai-python#1059). Revisit only with the durability upgrade.
- Redis, or Redis + BullMQ, for the job registry. Rejected: BullMQ is a Node library (same sidecar objection as Mastra); a broker is unwarranted at ≤3 concurrent jobs on one process; Postgres job rows without durable execution cannot resume a dead dive — they would only be a tombstone the sheet's failed status already conveys.
- Cognee's own modes for the whole dive. Partial: `GRAPH_COMPLETION_DECOMPOSITION` (splits 1–5 subqueries, retrieves per subquery, synthesizes, ~60 s) is the recorded fallback if hand-planned sub-questions disappoint; `AGENTIC_COMPLETION` stays rejected, now on a second ground — it requires exactly one dataset and the Book set is two. No Cognee completion type returns anything but a single answer string, so the guarded multi-page essay contract lives in `serve.py` regardless.
- Keeping the streamed prose as the phase-1 answer with the selection above it. Rejected: the Quote selection is the first answer (CONTEXT.md); the prose would either compete with it or be generated unseen.

## Consequences

- ADR 0005's phase-3 auto-start is overturned (amendment noted there); its tabs, timers, and truncation-continuation machinery stand, and its `/next-tier-recall` plumbing stays live until the dive ships — the README's Deep dive section records the decided contract and marks the live engine.
- The first-answer contract tests, the README First answer section, and the benchmark's fast-chat baseline (TKI set) re-record when the Quote selection ships; the old baseline run is archived with the contract change noted in `benchmark/setup.json`.
- A dive takes minutes by design («slow is allowed» stays in the glossary); the phase-3 timer chip carries it, started by the button.
- Glossary (CONTEXT.md, 2026-09-12): Quote selection and Deep dive added; Quoted answer loses the first-answer identity; Next-tier search retired as a name.
